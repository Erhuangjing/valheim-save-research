## 二、为什么必须"走进去"才开始建？

Valheim 的服务器**只加载玩家附近的区域**（zone）。插件要在某个位置建件，必须先让那块区域被加载，否则建不出来。

所以插件的流程是：

```
服务器启动
  → 读件清单（1805 件）✓
  → 检查落点区域是否加载 ──未加载──→ 日志输出「等待你走近」→ 等 30 帧 → 再查
                          └─已加载─→ 采样地面 → 开始建房（每批 60 件，约 50 秒建完）
```

**你走到落点，区域加载了，它就开始干活。**

## 四、落地位置和高度是怎么算的

| 项目       | 说明                                                                      |
| -------- | ----------------------------------------------------------------------- |
| **落点中心** | `(-262, 270)` —— 你家主宅东侧约 15 米                                           |
| **高度基准** | 落点范围地面的**中位数**（保持整栋建筑刚性、不变形）                                            |
| **石台基**  | 蓝图最低件 py = **−6.36**（7 米高石台基，自带石楼梯）。坡地上埋深最多约 2 米，台基仍有 5 米露出地表 → 能正常接上支撑 |

**为什么要这样**：上一次崩坏的根因是把**整个石台基（6.4 米）埋进了地形内部**，游戏判不到支撑 → 石墙、石柱、石楼梯成片崩塌（实测崩了 317 件，全在 Y 34~40 的地下范围）。这次改为"整栋统一基准"，埋深受控。

## 五、想调参数？改配置文件后重启服务器

文件：`<VALHEIM_SERVER_DIR>\BepInEx\config\com.world.bpbuild.cfg`

| 配置项                        | 当前值            | 说明                                  |
| -------------------------- | -------------- | ----------------------------------- |
| `Enabled`                  | `true`         | 总开关                                 |
| `OriginX` / `OriginZ`      | `-262` / `270` | 落点中心坐标                              |
| `YOffset`                  | `0`            | 整体抬高（正数=抬高）。**如果还崩就填 `2`**，让台基再露出一截 |
| `PerPieceGround`           | `false`        | 保持 `false`（`true` 会让建筑在坡地上错层）       |
| `BatchSize` / `FrameDelay` | `60` / `10`    | 每批件数 / 每批间隔帧（越大越快但越卡）               |

> 改完**必须重启服务器**才生效（游戏把世界装在内存里，运行中改文件不读）。

## 七、这套东西是什么（原理一句话）

`BepInEx` 是模组框架；我写的插件 `XiBpBuilder.dll` 挂进服务器进程，在世界加载后调用**游戏自己的 ZDO 创建接口**（`ZDOMan.CreateNewZDO`）把蓝图逐件建成真实物件。

**所以**：

- 生成的是**真实建筑数据**，不是"幽灵件"
- 你和朋友**都不用装任何模组**（只装在服务器）
- 落地完想删插件也行，建筑还在（它就是世界数据）

**已知限制**：

- 与 `-crossplay` 不兼容（你的服务器没开，无影响）
- 朝向用的是蓝图原始 yaw 值，斜面屋顶（45°/26°）和斜梁可能需要目视确认
- 有 13 种构件（石拱、石柱、木梁、木龙首、原木段等）你世界里从没造过，靠蓝图数据直接创建，外观需要你看一眼

## 八、如果还崩 / 位置想换

告诉我现象，我这边有现成的后手：

| 情况         | 处理                                                               |
| ---------- | ---------------------------------------------------------------- |
| 还崩         | 把 `YOffset` 改成 `2` 或 `3` 重启（让台基多露出一截）                            |
| 地形太坡想换位置   | 我扫过你的地形，`(-345, 315)` 是个天然平地（地形跨度仅 1 米，距你家 62 米），改两行配置就行         |
| 想让房子自己适应坡地 | 把 `PerPieceGround` 改成 `true`（但建筑会错层，不推荐）                         |
| 想整平原地      | 用游戏里的**锄头**（Hoe）的"平整地形"功能，需要石头；或者我给你做地形压平插件（要走游戏的地形 RPC，需要再开发一轮） |
