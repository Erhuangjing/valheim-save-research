### 残留实体（石头/树/灌木）—— 边际因素

### 接地几何 —— 干净（这条推翻了上一轮的推断）

冻结磨损后，对每一件跑游戏同款的盒体判定
（`Physics.OverlapBoxNonAlloc(包围盒中心, 半长+0.15, 掩码 piece/Default/static_solid/Default_small/terrain)`）：

```
盒内命中地形 33 | 盒内命中别的构件 3695 | 盒内命中其它物体 0 | ★三者皆无 0
```

**4625 件里 0 个孤立件**，每一件身边都有地形或别的构件。
所以"悬空够不着地面"这个说法**不成立**。

## 3. 收敛到机制：支撑链衰减

### 决定性证据：支撑值随时间单调衰减，且与死亡同步收敛

```
12:31:58  support[45.7 ~ 1500.0]   件数 4628   ← 刚开始
12:32:28  support[37.6 ~ 1500.0]   件数 4606
12:32:58  support[31.5 ~ 1500.0]   件数 4596
12:33:28  support[24.6 ~ 1500.0]   件数 4596
12:33:58  support[21.7 ~ 1500.0]   件数 4596   ← 稳定
```

**支撑最小值被一路压到 21.7，件数恰好在同一时刻停止下降。**
而冻结磨损（`UpdateSupport` 完全不跑）时件数恒定、零死亡 → 死亡 100% 由磨损/支撑流程产生。

### 为什么总是石构件

`WearNTear.UpdateSupport`（930 行）的传递公式是**乘性衰减**：

```csharp
num3 = Mathf.Max(num3, support2 - horizontalLoss * 距离 * support2);   // = support * (1 - loss*dist)
```

每一跳都乘一个 <1 的因子，链一长就指数衰减。
木构件（`下限 = 10.0`，实测最小 support 45.7~100）**永远不会超限**；
石构件（`最大 support = 1500`，下限高得多）的链尾会先跌破 → 被剪掉。

这也解释了全部丢失件都是石构件（`stone_wall_1x1` / `stone_wall_2x1` / `stone_stair` / `stone_floor_2x2`）。

### 为什么死的是最底层

**地面锚点极少**：4625 件里只有 **33 件**的盒子里真有地形碰撞体。
其余全部依靠件对件的链。最底层那圈石基础在水平方向上铺得很开，
而锚点只有 33 个 → 横向链的**末端**就是链尾 → 从链尾开始被剪。
上层结构由大量立柱/梁垂直承托，链短，所以 `py ≥ +0.50 以上 4300 多件零丢失`。

### 为什么 `★支撑不足` 恒为 0

`UpdateWear` 一旦发现 `HaveSupport()` 为假就**当帧造成 100% 伤害**，
件在采样间隔内就没了 —— 瞬时采样永远抓不到"正挨饿"的状态。
**判断崩塌只能看件数随时间的变化。**

## 4. 回答"地形和蓝图完全一致，崩塌概率会不会小很多"

**不会显著降低。** 三条证据：

1. `YOffset ±0.25` 两个方向的基准位移，丢失数**一动都不动**（29 → 29）
2. 几何上没有任何孤立件 —— 没有"够不着地面"的件可救
3. 死亡与**支撑值衰减**同步收敛，而不是与地形误差同步

**真正的杠杆是「地面锚点数量」，不是「地形贴合度」。**
锚点从 33 增到 41，丢失数没变 → 说明要达到质变，锚点得**成数量级**增加
（让整圈石基础的盒子都能碰到地形），而不是靠整体位移几十厘米。

这也是为什么**「接管 UpdateSupport」在原版里不是作弊，而是必需补丁**：
支撑链在多件蓝图上是不可收敛的，剪链尾是系统自己的收敛方式。

## 附：本轮新增的插件能力（v0.27.x）

| 功能 | 说明 |
|---|---|
| `[Gap] Enabled` | 间隙体检：逐件测「碰撞体底面 → 地形表面」间隙 + 跑游戏同款盒体判定预测谁会掉 |
| `[Gap] FreezeWear` | 冻结 `WearNTear.UpdateWear`，零销毁干扰下量几何（两步法第一步） |
| 支撑阈值对照 | 按构件名聚合 `support` 最小/最大值与该材料的 `GetMinSupport()` 下限，并统计低于下限的件数 |

**注意**：冻结磨损时 `UpdateSupport` 不跑，`support` 保持初值（观测到恒为 100），
所以"冻结下的支撑值"没有参考意义，只有盒体判定和间隙有意义。
