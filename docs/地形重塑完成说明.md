## 三、技术上最大的一个坑（值得记一笔）

Valheim 的地形高度有**两份数据**，我一开始改错了那份：

```
Heightmap.m_heights      ← ★ 游戏实际使用的高度（改这个才生效）
TerrainComp.m_levelDelta ← 只是「相对原始高度的偏移」，供存档序列化
```

**只改 delta 的后果**：写了 delta=5.83，但实际地面高度纹丝不动（还是 43.01）—— 表面上完全"没生效"。必须**两个都写**：`heights` 负责当前生效，`delta` 负责存档持久化。
